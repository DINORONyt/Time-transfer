# Лабораторная работа №1: Разработка линейных алгоритмов и программ

**Вариант 12: Перевод времени**

## Описание проекта

Данный проект представляет собой консольное приложение на языке C#, разработанное в рамках лабораторной работы №1 по дисциплине "Разработка линейных алгоритмов и программ". Программа выполняет три задачи по переводу времени из секунд в различные форматы.

### Функциональность

1. **Задача 1 (базовая)** — перевод секунд в минуты и секунды
   - Пример: 150 сек = 2 мин 30 сек

2. **Задача 2 (средняя)** — перевод секунд в часы, минуты и секунды
   - Пример: 3725 сек = 1 ч 2 мин 5 сек

3. **Задача 3 (расширенная)** — вычисление процента от суток
   - Результат выводится с двумя знаками после запятой

## Технологии

- **Язык программирования:** C# 7.0
- **Среда разработки:** Microsoft Visual Studio
- **Тип приложения:** Консольное приложение (.NET Framework / .NET Core)

## Установка и запуск

### Требования
- .NET Framework 4.5+ или .NET Core 2.0+
- Visual Studio 2017+ (рекомендуется) или любая другая IDE с поддержкой C#


1. После запуска отображается меню с выбором задач:

   ЗАДАЧИ:
   1. Перевод секунд в минуты и секунды
   2. Перевод секунд в часы, минуты и секунды
   3. Процент от суток
   4. Выход из программы

   Введите номер задачи (1-4):

2. Введите номер задачи (1-4)

3. Следуйте инструкциям программы — введите количество секунд

4. Программа выведет результат вычислений

5. Для возврата в меню нажмите любую клавишу


### Примеры работы

**Задача 1:**
Введите количество секунд: 150
РЕЗУЛЬТАТ: 150 сек = 2 мин 30 сек

**Задача 2:**
Введите количество секунд: 3725
РЕЗУЛЬТАТ: 3725 сек = 1 ч 2 мин 5 сек


**Задача 3:**
Введите количество секунд: 3600
РЕЗУЛЬТАТ: Процент от суток: 4.17%


## Обработка ошибок

Программа включает валидацию ввода:
- Проверка на пустой ввод
- Проверка на корректность числа (только целые числа)
- Проверка на неотрицательные значения
- Обработка некорректного выбора пункта меню
